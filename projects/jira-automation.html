Jira Automation

The skill I lean on most: a library of Jira automation rules running at two levels — domain-wide governance rules and team-specific rules — that replaced manual board admin with consistent, rule-driven workflows.

Role
Senior Scrum Master, automation owner
Tools
Jira Automation · JQL
Scope
Domain-level rules + 4 team-specific rule sets
01 · Problem
02 · Approach
03 · Solution
04 · Impact

Problem

Every team was handling the same repetitive Jira admin — status transitions, SLA/ageing flags, label hygiene, notification routing — by hand, in slightly different ways. That inconsistency made the data underneath any rolled-up report harder to trust, and every new team meant reinventing the same rules from scratch.

Approach

Rather than one rigid rule set, automation needed to work at two levels at once: rules that had to hold true for every team in the domain, and rules a team could tailor for how it actually works day to day.

  • Built domain-wide governance rules — agreed with RDEs — covering the non-negotiables: hierarchy integrity, mandatory fields, and cross-project linking
  • Layered team-specific rule sets on top for each team's own workflow quirks — custom transitions, component-based routing, notification preferences
  • Used JQL-driven triggers so rules stay precise about exactly which issues they touch, instead of blunt, hierarchy-wide automation

Solution

A running library of automation rules covering auto-transitions on linked-issue status change, SLA and ageing alerts before something goes stale, label and field hygiene checks, and routing notifications to the right channel instead of flooding everyone. Domain rules ship once and apply everywhere; team rules stay owned by each team without breaking the shared baseline.

Impact

Manual Jira admin dropped sharply across all four teams, and the data quality issues that used to surface in leadership reporting became far rarer — directly feeding into the reliability of the Jira Quality Gates checks and the value-stream reporting layer. New teams now onboard onto the domain rule baseline in a fraction of the time it used to take to hand-build their automation from zero.
