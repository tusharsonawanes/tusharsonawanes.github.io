Confluence Table Transformer

An automation that turns raw Confluence capacity tables into a sprint-ready view for planning, removing a manual weekly reformatting task.

Role
Senior Scrum Master, process automation
Tools
Confluence · Power Automate
Team
4 teams, Data Tribe
01 · Problem
02 · Approach
03 · Solution
04 · Impact

Problem

Team capacity data lived in Confluence tables maintained by each team individually, in slightly different formats. Every sprint planning cycle, pulling that into a usable capacity view meant manually copying, reformatting, and reconciling four tables by hand.

Approach

Rather than push all teams onto a new tool, the fix worked with the tables they already maintained.

  • Standardized the minimum table structure each team needed to keep (without changing how they logged capacity day-to-day)
  • Built a Power Automate flow to pull, normalize, and merge the tables into one capacity view
  • Scheduled it ahead of each sprint planning session so the merged view is ready without anyone requesting it

Solution

An automated pipeline that reshapes each team's Confluence capacity table into one normalized planning view, published before sprint planning starts — with no manual copy-paste step.

Impact

Removed a recurring manual reporting task each sprint and eliminated the formatting inconsistencies that used to cause capacity-number disputes in planning.
