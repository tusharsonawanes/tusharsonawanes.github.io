Data Lineage Tracker

An interactive explorer that traces how a metric moves from source table to executive dashboard, so a broken number can be diagnosed in minutes instead of a cross-team hunt.

Role
Senior Scrum Master, data & reporting workstream
Tools
MicroStrategy · SQL
Team
Digital Touchpoint Analytics, Data Tribe
01 · Problem
02 · Approach
03 · Solution
04 · Impact

Problem

When a number on an executive MicroStrategy dashboard looked wrong, no one owned a clear map of where it actually came from. Diagnosing a discrepancy meant pulling in a data engineer, a report owner, and whoever last touched the relevant SQL — often over several days, across a value stream serving two products.

Approach

Rather than commission a full enterprise data-catalog rollout, the workstream scoped a lighter tool aimed squarely at the reports leadership actually reads.

  • Inventoried the source tables and transformation steps feeding the highest-traffic executive dashboards
  • Defined a simple lineage schema — source, transform, destination — that report owners could maintain themselves
  • Prioritized an interactive view over a static document, so anyone could trace a metric without asking a specific person

Solution

An interactive HTML lineage explorer where a metric can be clicked and its full path — source table, each SQL transformation, and the dashboard it lands on — is shown as a connected graph. Report owners update the underlying data as pipelines change, keeping the map current without engineering effort.

Impact

Diagnosing a dashboard discrepancy went from a multi-day, multi-person hunt to a self-serve lookup for the report owner in most cases. The tool is now the first stop before escalating a data-quality question to engineering.
